# Weather ETL Pipeline

## Project Overview
Weather Data ETL Pipeline developed using Python and Google Colab.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- SQLite
- Google Colab

## Features
- CSV Data Extraction
- Data Cleaning
- Missing Value Handling
- Duplicate Removal
- Weather Data Transformation
- SQLite Database Integration
- Weather Analytics Dashboard

## Project Workflow
1. Extract weather data from CSV.
2. Clean and transform the data.
3. Load data into SQLite database.
4. Generate weather analytics dashboard.
